# ADR-0015: Módulo de interpolação compartilhado

- **Status:** Proposto
- **Data:** 2026-10-20
- **Decidido por:** dono do projeto, em conversa de planejamento com o Claude
- **Prioridade:** Média
- **Revisão por IA:** [ ] pendente
- **Revisão humana:** [ ] pendente

## Contexto

A ferramenta de mesclagem entre formas (Vetor) e as fontes variáveis (Tipografia) resolvem quase o mesmo problema: interpolar formas com estrutura de pontos compatível. A diferença: na mesclagem, inserir pontos para casar as formas é aceitável. Nos masters de uma fonte variável, inserir pontos altera em silêncio o desenho do tipógrafo.

## Decisão

- **Um crate `bivar-interp`** com:
  - correspondência de pontos entre formas;
  - **verificar compatibilidade:** estrito. Só diz se as formas são compatíveis e, se não forem, onde diferem. **Nunca altera a forma**;
  - **tornar compatível:** insere ou reordena pontos para casar as formas. **Permitido só na mesclagem.** Os masters de fontes variáveis usam apenas a verificação, e uma incompatibilidade aparece para o tipógrafo corrigir (princípio 5);
  - interpolação de paths, cores, traçados e degradês.
- **Quem usa:**
  - o nó Mesclagem (Fase 1a): verificar e tornar compatível;
  - os masters de fontes variáveis (Fase 2b): só verificar.

## Alternativas consideradas

- **Implementações separadas:** duplicação e comportamento divergente.

## Consequências

- **Precisa estar pronto na 1a,** com a robustez exigida pela 2b.
