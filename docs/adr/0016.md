# ADR-0016: Licença GPL-3.0, DCO e contribuições com IA

- **Status:** Proposto
- **Data:** 2026-10-20
- **Decidido por:** dono do projeto, em conversa de planejamento com o Claude
- **Revisão por IA:** [ ] pendente
- **Revisão humana:** [ ] pendente

## Contexto

O projeto é para todo mundo usar e não deve virar produto fechado de terceiros.

## Decisão

- **Licença:** **GPL-3.0-or-later** para o programa e para os plugins.
- **Registro oficial:** aceita só plugins gratuitos (política, não licença).
- **Contribuições:** pelo **DCO** (`Signed-off-by`), sem CLA.
- **Contribuições feitas com IA:** aceitas, com declaração de uso, comportamento testado por uma pessoa e código revisado por IA e por ferramentas automáticas. Revisão humana do código é bem-vinda, mas hoje não é prometida (o dono não programa).
- **Aviso de IA:** "feito com auxílio de IA" na interface e no README.
- **Papel humano:** registrado nos ADRs, porque a proteção de direito autoral de código gerado por IA é incerta em algumas jurisdições.

## Alternativas consideradas

- **MIT/Apache-2.0:** permitiria versões fechadas.
- **MPL-2.0:** meio-termo, que não foi considerado suficiente.

## Consequências

- **Compatibilidade:** todas as dependências precisam ser compatíveis com a GPL-3.0 (ADR-0012).
