# ADR-0005: Modelo de dados compatível com CRDT desde o início

- **Status:** Proposto
- **Data:** 2026-10-20
- **Decidido por:** dono do projeto, em conversa de planejamento com o Claude
- **Validação do auditor:** [ ] pendente

## Contexto

A colaboração P2P na rede local chega depois da Fase 2, mas adaptar um modelo de dados a CRDT depois é uma das reformas mais caras possíveis.

## Decisão

- **Desde o início:** o modelo de dados e as operações são projetados para junção sem servidor desde o primeiro dia.
- **Biblioteca candidata:** **Loro**, por ter árvore com movimentação e texto rico. Alternativas: Automerge e Yrs.
- **Arquivos grandes** (imagens, áudio) ficam fora do CRDT, identificados pelo hash do conteúdo.
- **Validação pós-junção:** grafos inválidos após a junção, como um ciclo, entram em estado de conflito (ADR-0004).
- **Raster:** vale a última pincelada por bloco.

## Alternativas consideradas

- **CRDT só depois:** reescrita do núcleo.
- **Transformação operacional com servidor:** contraria o princípio de funcionar sem servidor.

## Consequências

- **Custo:** desempenho e complexidade maiores no núcleo.
- **Pedido ao auditor:** um protótipo de benchmark com documentos grandes.
