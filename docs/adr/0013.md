# ADR-0013: Scripts em JS/TS e plugins em WebAssembly, com uma única API

- **Status:** Proposto
- **Data:** 2026-10-20
- **Decidido por:** dono do projeto, em conversa de planejamento com o Claude
- **Validação do auditor:** [ ] pendente

## Contexto

Automação para quem não programa (macros), scripts para quem programa e uma comunidade que amplia o programa.

## Decisão

- **Scripts:** em **JS/TS**, com o motor escolhido pelo auditor.
- **Plugins:** em **WebAssembly**, em qualquer linguagem que compile para Wasm.
- **Uma API pública só,** versionada, que emite operações (ADR-0002).
- **Sandbox:**
  - só o documento aberto;
  - pastas, só as autorizadas;
  - rede bloqueada.
- **Permissões de plugins:** declaradas e aprovadas na instalação.
- **Assinatura:** plugins assinados pelo autor; sem assinatura, há aviso.
- **Gravador de macros:** gera scripts JS.
- **Modo sem interface:** pela linha de comando.
- **Estabilidade da API:** ela só é congelada depois da Fase 3.

## Alternativas consideradas

- **Python embutido:** difícil de isolar.
- **Dois interpretadores:** dobra a manutenção e a superfície de ataque.

## Consequências

- **Plugins com shaders de GPU próprios:** ficam para uma fase avançada.
