# ADR-0003: Dono + referência para nós compartilhados

- **Status:** Proposto
- **Data:** 2026-10-20
- **Decidido por:** dono do projeto, em conversa de planejamento com o Claude
- **Revisão por IA:** [ ] pendente
- **Revisão humana:** [ ] pendente

## Contexto

Camadas formam uma árvore (cada coisa tem um dono), mas grafos permitem que um nó alimente vários objetos.

## Decisão

- **Dono:** todo nó tem **um dono**, o objeto onde foi criado.
- **Referências:** usar o nó em outro lugar cria uma **referência**, mostrada com ícone de vínculo na camada.
- **Aviso:** ao editar um nó referenciado, o painel avisa "afeta N objetos".
- **Desvincular:** cria uma cópia independente.
- **Modelo familiar:** é o mesmo dos estilos e variáveis do Figma.

## Alternativas consideradas

- **Sem dono (grafo puro):** a projeção em camadas fica ambígua.
- **Proibir compartilhamento:** perde-se boa parte do poder do grafo.

## Consequências

- **Precisa existir no núcleo:** o modelo de referências.
- **Remover o dono:** exige uma regra (transferir o dono ou converter as referências em cópias). A regra ainda precisa ser definida.
