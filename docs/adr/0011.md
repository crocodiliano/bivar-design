# ADR-0011: Leitura de arquivos externos só em Rust, com fuzzing

- **Status:** Proposto
- **Data:** 2026-10-20
- **Decidido por:** dono do projeto, em conversa de planejamento com o Claude
- **Prioridade:** Alta
- **Revisão por IA:** [ ] pendente
- **Revisão humana:** [ ] pendente

## Contexto

Arquivos maliciosos (SVG, fontes, imagens) são o vetor de ataque mais comum em programas de design.

## Decisão

- **Leitores em Rust:** todo leitor de formato externo é escrito em Rust ou usa uma biblioteca Rust.
- **Fuzzing:** todo leitor tem um alvo de fuzzing em `fuzz/` (pasta corrigida em 2026-10-30, com aprovação do dono; ferramenta, versão *nightly* e compilação automática no [ADR-0024](0024.md)).
- **Validação:** o resultado da leitura é validado antes de virar operações.
- **Exceção:** quando não houver alternativa em Rust (ex.: hinting automático, RAW), o componente roda isolado, como processo separado ou equivalente, e é registrado num ADR próprio.

## Alternativas consideradas

- **Bibliotecas C/C++ diretamente no processo:** risco de corrupção de memória.

## Consequências

- **Custo:** alguns formatos ficam com suporte limitado até existir um leitor Rust maduro.
