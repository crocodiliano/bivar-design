# ADR-0002: Toda mudança é uma operação

- **Prioridade:** Alta

## Contexto

Interface, desfazer, scripts, colaboração P2P e recuperação de queda precisam de uma linguagem comum para mudar o documento.

## Decisão

- **Operações:** toda mudança é uma **operação serializável** no grafo: criar/remover nó, conectar/desconectar, mudar parâmetro, reordenar, mover na hierarquia.
- **Quem gera operações:** a interface, os scripts, os plugins e a rede. **Ninguém altera o estado diretamente.**
- **Desfazer:** é a lista de operações do próprio autor. Operações podem ser agrupadas em transações, de modo que um script inteiro se desfaz com um único Ctrl+Z.
- **Diário:** as operações formam o diário usado para a recuperação de queda (ADR-0010).
- **Validação:** toda operação passa pela mesma validação, qualquer que seja a origem.

## Alternativas consideradas

- **Mutação direta com instantâneos para desfazer:** incompatível com CRDT e com scripts seguros.

## Consequências

- **Ganho:** desfazer, macros, scripts, P2P e recuperação saem da mesma base.
- **Custo:** toda funcionalidade nova precisa ser expressa como operações.
