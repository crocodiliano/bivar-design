# ADR-0014: Segurança do P2P

- **Status:** Proposto
- **Data:** 2026-10-20
- **Decidido por:** dono do projeto, em conversa de planejamento com o Claude
- **Prioridade:** Alta
- **Revisão por IA:** [ ] pendente
- **Revisão humana:** [ ] pendente

## Contexto

Colaboração na rede local, com 5 a 8 pessoas, sem servidor. Redes locais (coworking, café) não são seguras.

## Decisão

- **Identidade:** um par de chaves por usuário.
- **Convite:** por código ou QR code.
- **Criptografia de ponta a ponta.**
- **Assinatura:** toda operação é assinada pelo autor e validada contra a lista de acesso, que é assinada pelo dono.
- **Papéis:** dono, editor, comentarista e visualizador.
- **Operações recebidas:** tratadas como entrada não confiável.
- **Histórico:** registra quem fez o quê, com marcos nomeados.
- **Rede:** só LAN, com a camada de rede isolada para um eventual relay futuro.

## Alternativas consideradas

- **Sem autenticação ("rede local é confiável"):** inseguro.

## Consequências

- **Limite honesto:** "visualizador" impede edição, mas não impede cópia de dados recebidos.
