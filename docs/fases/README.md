# Roadmap e especificações das fases

**Não há datas.** Cada entrega termina quando todos os seus critérios de aceite passam. As especificações detalhadas só são escritas quando a fase vai começar, para não engessar decisões que ainda vão amadurecer. Hoje estão detalhadas a Fase 0, o Núcleo e a Fase 1a.

| Etapa | Persona | Entregas | Especificação |
| --- | --- | --- | --- |
| Fase 0 | Fundações | Repositório, provas de conceito (interface, renderizador, texto), revisão por IA dos ADRs, bibliotecas pendentes | [fase-0.md](fase-0.md) |
| Núcleo | — | Grafo, operações, arquivo, render, texto, cor, módulos | [nucleo.md](nucleo.md) |
| Fase 1 | Vetor | 1a ilustração · 1b UI e handoff | [fase-1a.md](fase-1a.md) · 1b a escrever |
| Fase 2 | Tipografia | 2a estática · 2b variável | a escrever |
| Fase 3 | Animação | 3a clássica · 3b interativa e rigging · 3c procedural | a escrever |
| Fase 4 | Interface (editorial) | 4a base · 4b documento longo · 4c digital e dados | a escrever |
| Fase 5 | Foto | 5a revelação · 5b retoque · 5c avançado | a escrever |
| Fase 6 | Áudio | 6a base · 6b espectrograma e gerador | a escrever |
| Fase 7 | 3D | 7a base · 7b 3D → vetor | a escrever |
| Depois | — | Runtime web, perspectiva avançada, path tracing, narração | — |

## Recursos transversais

| Quando | O que entra |
| --- | --- |
| Desde o início | Código aberto, em repositório público no GitHub. Acessibilidade, tokens de tema, segurança (fuzzing, auditoria de dependências), modelo compatível com CRDT |
| Fim da 1a | **A comunidade passa a contribuir com código.** Entram scripts JS, gravador de macros e modo terminal |
| Fim da 1b | Comentários e tarefas, wiki do projeto, receitas de efeito |
| Fim da Fase 2 | Colaboração P2P na rede local |
| Fim da Fase 3 | API pública de plugins em WebAssembly |
