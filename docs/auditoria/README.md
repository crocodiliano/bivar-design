# Auditorias

Aqui ficam os relatórios de revisão do projeto:

- os relatórios do agente auditor (`.claude/agents/auditor.md`);
- as segundas opiniões de IAs de outras empresas;
- as revisões de voluntários da comunidade.

**Nome dos arquivos:** `AAAA-MM-DD-escopo.md`. Exemplo: `2026-11-02-adrs-0001-0018.md`.

> **Atenção:** por enquanto o projeto **não passou por auditoria humana**. Estes relatórios são feitos por IA e não substituem uma revisão de alguém experiente em Rust.
